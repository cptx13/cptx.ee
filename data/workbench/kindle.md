## guide

Based on [KindleModding](https://kindlemodding.org/jailbreaking/). Read it all before touching anything: a jailbreak only lets the Kindle run your own code, it changes nothing else by itself.

1. **Check the model and firmware** (Settings → Device info). Amazon patches jailbreaks in new firmware, and you can't go back to an older one until you are jailbroken, so don't update.
2. **Stop automatic updates** before you start. KindleModding's way is to [fill the storage](https://kindlemodding.org/jailbreaking/prevent-auto-update/) for a while so no update can download.
3. **Find your jailbreak** with the [jailbreak wizard](https://kindlemodding.org/jailbreak-wizard.html). It picks the right method for your model and firmware (WinterBreak, AdBreak and others).
4. **Run it**, following that method's page step by step.
5. **After the jailbreak**, update blocking and a package manager are set up for you. From there: [Homebrew](https://kindlemodding.org/jailbreaking/whats-next/installing-homebrew.html) and [KOReader](https://kindlemodding.org/jailbreaking/whats-next/getting-koreader/), the reader that makes it a different device.

## notes

- Don't factory reset a jailbroken Kindle without help. If something goes wrong, start with [Kindle recovery](https://kindlemodding.org/jailbreaking/faq/kindle-recovery.html).
- Don't let it update: one update can close the door for good.
